# 🌐 MoaClass Frontend (모아클래스 프론트엔드)

![MoaClass Logo](public/moaclass-icon.svg)

- 모아클래스(MoaClass)는 지역 기반 원데이 클래스/소모임 통합 플랫폼입니다.
- 클래스/모임 탐색, 일정 예약, 결제/포인트/쿠폰, 후기, 채팅, 알림까지 한 흐름으로 제공됩니다.
- 후기 데이터 기반 요약/활용하여 리뷰 품질 관리 및 유저의 의사결정을 지원합니다.

## 📅 개발기간

- 2026년 1월 26일 ~ 2026년 2월 25일 (총 5주)

## 🚀 배포 주소

- https://moaclass.vercel.app

## 🎯 주요 기능

### 1. 클래스 및 모임 탐색

- **맞춤형 필터링**: 카테고리, 지역, 난이도(입문/중급/상급), 가격대 등 상세 필터를 통해 원하는 클래스를 쉽게 찾을 수 있습니다.
- **키워드 검색**: 제목이나 내용에 포함된 키워드로 실시간 검색이 가능합니다.
- **지도 기반 위치 확인**: 클래스가 진행되는 정확한 위치와 찾아오는 길을 지도로 확인할 수 있습니다.

### 2. 일정 예약 및 관리

- **실시간 예약**: 클래스별 스케줄을 확인하고 원하는 시간대에 즉시 예약할 수 있습니다.
- **예약 현황 추적**: 마이페이지를 통해 신청한 클래스의 승인 상태 및 진행 일정을 한눈에 관리합니다.

### 3. 결제 및 포인트/쿠폰 시스템

- **안전한 결제**: 토스페이먼츠 연동을 통해 신용카드, 계좌이체 등 다양한 수단으로 안전하게 결제할 수 있습니다.
- **혜택 활용**: 회원가입이나 활동으로 얻은 포인트와 쿠폰을 결제 시 적용하여 할인 혜택을 받을 수 있습니다.

### 4. AI 기반 리뷰 및 품질 관리

- **생생한 후기**: 사진과 상세한 텍스트를 포함한 수강생들의 진솔한 리뷰를 확인할 수 있습니다.
- **AI 리뷰 요약**: 수많은 리뷰를 일일이 읽지 않아도 AI가 핵심 내용을 요약해 주어 의사결정을 돕습니다.

### 5. 실시간 소통 (채팅)

- **1:1 문의**: 클래스 신청 전후로 호스트(선생님)와 실시간으로 대화하며 궁금한 점을 해결할 수 있습니다.
- **모임 채팅**: 다수 참여자가 함께 소통하는 채팅방 기능을 제공합니다.

### 6. 스마트 알림 서비스

- **진행 상황 안내**: 예약 완료, 결제 성공, 클래스 일정 리마인드 등 주요 이벤트를 실시간 알림으로 받아볼 수 있습니다.

## 🛠 기술 스택 (Tech Stack)

### Core

- Framework: `Next.js 16` (App Router)
- Library: `React 19`
- Language: `TypeScript`
- Runtime/Package Manager: `Node.js`, `npm`

### Routing

- Primary: `next/navigation`, `next/link`
- Legacy coexistence: `react-router-dom v7`

### State Management

- Server State: `@tanstack/react-query v5`
- Client State: `zustand`
- Form State: `react-hook-form` + `zod` + `@hookform/resolvers`

### API & Real-time

- HTTP Client: `axios`
- Real-time: `socket.io-client`
- API Mocking: `MSW (Mock Service Worker)`
- Mock Data: `@faker-js/faker`

### UI & Styling

- Styling: `Tailwind CSS v4`
- UI Components: `shadcn/ui` + `Radix UI`
- Icons: `lucide-react`, `react-icons`
- Animation: `framer-motion`, `tailwindcss-animate`
- Toast: `sonner`

### Quality & Tooling

- Lint: `ESLint 9`
- Format: `Prettier`
- Test: `Vitest`, `Testing Library`, `jsdom`
- Git Hooks: `husky`, `lint-staged`

## 📁 프로젝트 구조 (Project Structure)

```text
src/
├── api/                # 도메인별 API 호출 함수
├── app/                # Next.js App Router 페이지/레이아웃
├── assets/             # 정적 리소스
├── components/
│   ├── ui/             # shadcn/ui 기반 공용 UI
│   ├── common/         # 공통 컴포넌트
│   ├── features/       # 도메인 기능 컴포넌트
│   └── providers/      # 전역 Provider(Query, OAuth, MSW 등)
├── config/             # 환경/설정 상수
├── constants/          # 공통 상수
├── hooks/              # 데이터 패칭/비즈니스 커스텀 훅
├── lib/                # QueryClient, socket, 유틸 설정
├── mock/               # MSW 핸들러/목 데이터
├── models/             # 타입/도메인 모델
├── store/              # Zustand 전역 상태
├── test/               # 테스트 유틸
├── utils/              # 순수 유틸 함수
├── v-pages/            # 레거시 페이지(점진적 마이그레이션 대상)
├── index.css           # 글로벌 스타일
└── main.tsx            # 레거시 엔트리
```

## 💡 개발 및 코딩 컨벤션

### 1) 상태 관리 전략

- 서버 데이터는 `React Query`로 관리하고, 쿼리 키 기반 캐싱/무효화 전략을 사용합니다.
- UI 중심 전역 상태는 `Zustand`로 경량 관리합니다.
- 폼 상태와 검증은 `React Hook Form + Zod` 조합을 기본으로 사용합니다.

### 2) 컴포넌트 설계 원칙

- `ui`의 공용 컴포넌트를 조합해 `features` 단위 기능 컴포넌트를 구성합니다.
- 비즈니스 로직과 데이터 연동은 커스텀 훅으로 분리해 뷰 컴포넌트의 책임을 줄입니다.

### 3) API/실시간 통신

- HTTP 통신은 `axios` 클라이언트로 통일합니다.
- 실시간 알림/채팅은 `socket.io-client`를 통해 처리합니다.
- 백엔드 연동 전/테스트 상황에서는 `MSW`로 API를 모킹합니다.

### 4) 품질 관리

- 커밋 전 `husky + lint-staged`로 린트/포맷을 자동 실행합니다.
- 단위/컴포넌트 테스트는 `Vitest + Testing Library` 기반으로 작성합니다.

## ⚙️ 시작하기 (Getting Started)

### 1. 패키지 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

### 3. 프로덕션 빌드

```bash
npm run build
```

### 4. 프로덕션 실행

```bash
npm run start
```

### 5. 린트 체크

```bash
npm run lint
```

### 6. 테스트 실행

```bash
npm run test
```
